# Worlds 2026 即時面板

英雄聯盟 2026 全球總決賽的即時比賽面板：比分、經濟、出裝、大事件時間軸、即時勝率、選角（BP）預測與模擬、賽後復盤。

純靜態網頁，資料由瀏覽器直接向 LoL Esports 官網使用的公開 API 與 Riot Data Dragon 取得。

## 功能

- **即時比賽**：雙方擊殺、經濟、塔、小龍、巴龍、水晶兵營；10 位選手的英雄、等級、KDA、CS、出裝、符文；暫停時間會自動扣除
- **事件時間軸**：首殺、擊殺、小龍/巴龍、推塔、完成裝備、勝率大幅擺盪
- **即時勝率**：邏輯斯迴歸模型（經濟差、擊殺、塔、龍、龍魂、遠古龍、巴龍、兵營、時間、隊伍 Elo）
- **選角 BP**：看直播點選輸入，即時計算下一手選/禁機率與本局出場機率；可模擬剩餘 BP、手動調整先發與先選方
- **賽後復盤**：比賽結束後自動推導輸方敗因

## 本機執行

```bash
python -m http.server 8765
```

開啟 http://localhost:8765（直接雙擊 index.html 無法讀取資料檔）。

## 更新模型資料

```bash
python build_history.py      # 近期職業賽選角資料 → history.json
python build_winprob.py      # 抽樣場上狀態並訓練勝率模型 → winprob_model.json
```

## 注意

- 使用的是 lolesports.com 網站內部 API，非官方公開 API，隨時可能變動。
- BP 輸入、陣容調整、設定都存在各自的瀏覽器中，不會在使用者之間同步。
- 選角階段官方沒有即時資料，BP 需手動輸入；開局後會自動以官方資料補齊。
